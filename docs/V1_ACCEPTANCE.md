# V1 验收记录

日期：2026-10-08（Asia/Shanghai）。状态：**功能完成，发布验收未完成**。本页记录第七批本机可执行检查；没有结果的场景保持待验收，不以自动化模拟替代物理操作。

## 环境与边界

Windows 11 家庭版，build 26200；i7-12700H（14 核／20 逻辑处理器）；约 40 GiB 内存；RTX 3070 Laptop GPU 与 Intel Iris Xe。硬件元数据：`artifacts/batch7-hardware.json`。测试使用合成内容、独立资料目录和已有模型副本。未下载模型，未使用用户资料，未上传发布包。

## 本机验收

- 完整 CI 已通过：131/131 测试，Release 0 警告／错误、格式通过；真实桌面回归 37 项、桌宠生命周期 12 项、迁移 8 项通过。命令与证据见 [VERIFICATION.md](VERIFICATION.md)。
- 真实 UI 端到端通过 13 项：桌宠 → 记录作品／标签 → 混合搜索／提问 → 来源 → 编辑 → 备份／恢复；使用既有本地模型、禁止下载，且检查回答未降级、来源 ID 正确。证据：`artifacts/batch7-e2e-02/e2e-result.json`。
- 两种容量索引、检索及桌面耗时已测；63 条／28 题检索门槛通过，仍有 2/3 无答案题误召回和提示复述缺陷。详见 [性能与质量记录](PERFORMANCE.md)，不据此宣称问答全部正确。
- AI 关闭、模型缺失、索引不完整已在本次端到端测试验证；运行期故障恢复 11 项、独占端口／所属进程清理、宿主突然退出的清理均通过，AiSmoke 退出 0。证据：`artifacts/batch7-ai-01/`。已有组件以禁止下载方式准备成功，但没有实施整机断网。
- 自包含代码已通过当前系统独立启动：新进程、无效 DOTNET_ROOT、受限 PATH，实际加载包内 CLR；新资料库和 v1 合成库各 7 项通过，第二实例转发、窗口关闭后宿主驻留及菜单退出均已验证。此项不等于干净操作系统验收。

## 待人工／独立环境验收

- 单屏／双屏、负坐标、100%／150%／200% 缩放、任务栏工作区、副屏拔插、物理拖动与托盘恢复。步骤：在每种配置记录灵感、拖至屏幕边缘、隐藏恢复，再拔插副屏，确认入口可见且位置持久化。几何单测及模拟点击不能勾选此项。
- 真实键盘焦点与 Tab 顺序、Ctrl+Enter／Esc、未保存草稿确认、高对比度与可读性。自动化入口采样两种容量均为 29/30 次即时焦点；追加严格焦点等待的新进程探针未全部通过，原因待实机区分。步骤：全程只用键盘完成记录、编辑、取消与搜索，再使用系统高对比度复测；记录观察者、设备和结果。当前程序化文本赋值不是打字速度。
- 干净 Windows 10 22H2 与 Windows 11 x64 普通账户：无 SDK 启动、首次组件准备、完全断网后的已有组件恢复。当前开发机无法代替这两个系统镜像。
- CPU-only、8GB 与 16GB 目标机器的容量／内存压力。当前 GPU 自动调度开发机实测仅适用于该次运行；支持边界见 [PERFORMANCE.md](PERFORMANCE.md)。
- GitHub Actions 远端运行、代码签名及对外发布。本地构建通过不代表远端验证。
