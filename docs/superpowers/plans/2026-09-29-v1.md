## Interfaces

Domain: Idea, Project, Tag, RetrievalQuery, SearchResult, EmbeddingRecord, ChatAnswer.
Application: IIdeaRepository, IProjectRepository, ITagRepository, IEmbeddingRepository, IBackupStore, IEmbeddingProvider, ILLMProvider, IRetriever, IExporter, IAppLog.
Infrastructure owns SqliteStore, ConfigurationStore, JsonFileLog, JsonExporter and MarkdownExporter.
Retrieval owns FtsRetriever, VectorRetriever, HybridRetriever, SemanticIndexer, RagPipeline.
AI owns OllamaProvider. Desktop owns window coordination and IPetRenderer.

All slow service operations take CancellationToken; synchronous SQLite APIs run on a worker with a shared maintenance gate. Mutations invalidate vectors in the same transaction. Restore excludes concurrent database operations. Repository results are immutable snapshots.
